# ALTAF ARABIC — Scalable Platform V2

هذه النسخة ليست إعادة تصميم فقط؛ إنها محرك بيانات قابل للتوسع.

## الهدف
- دعم الكتاب الأول: الوحدات 1–16.
- إضافة الكتاب الثاني لاحقًا دون إعادة كتابة واجهة المنصة.
- تحميل المحتوى من ملفات مستقلة بدل حشر كل البيانات داخل HTML واحد.
- استخدام MP3 كملفات خارجية حقيقية، لا Base64 داخل HTML.
- دعم مئات/آلاف عناصر التعلم مع بنية موحدة.

## البنية
- `ALTAF_ARABIC.html` — واجهة التطبيق ومحرك العرض.
- `data/catalog.js` — فهرس الكتب.
- `data/books/book1/unitNN.js` — ملف مستقل لكل وحدة.
- `data/books/book2/` — مساحة الكتاب الثاني.
- `data/conversations/C01.js ... C12.js` — محادثات مستقلة.
- `assets/audio/core/` — 91 ملفًا أساسيًا حقيقيًا.
- `assets/audio/conversation/` — 244 ملفًا، عربي/إنجليزي منفصل.
- `schemas/` — عقود البيانات الموحدة.
- `templates/UNIT_TEMPLATE.json` — قالب إضافة أي وحدة جديدة.

## إضافة الوحدة 9–16
لا تغيّر HTML. فقط أنشئ: `data/books/book1/unit09.js` مثلًا، بنفس بنية القالب، ثم حدّث العنوان/الفهرس عند الحاجة.

## إضافة الكتاب الثاني
أنشئ مجلدًا مثل `data/books/book2/` وملفات `unit01.js`, `unit02.js`... ثم أضف سجل الكتاب في `data/catalog.js`.

## الصوت
- الوحدات: `U{unit}_D{dialogue}_S{sentence}.mp3`
- المحادثة: `C{conversation}_S{sentence}_AR.mp3` و `C{conversation}_S{sentence}_EN.mp3`
- ممنوع تضمين الصوت داخل HTML بصيغة Base64 في الإصدارات القادمة.

## التشغيل المحلي
بسبب سياسات المتصفح مع الملفات المحلية، شغّل مجلد المنصة عبر خادم محلي، مثل:
`python -m http.server 8000`
ثم افتح `http://localhost:8000/ALTAF_ARABIC.html`.

## التوسع المستقبلي
الواجهة تستخدم storage adapter يمكن لاحقًا ربطه بـ Canva Forms/Sheets أو قاعدة بيانات خارجية دون إعادة بناء طبقة العرض.

## قاعدة مهمة
المحتوى التعليمي يُدخل من المصدر المعتمد فقط. المحرك لا يخترع نصوصًا للوحدات التي لم تدخل بعد.
