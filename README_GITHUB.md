# ALTAF ARABIC — Scalable Platform V2

GitHub Pages test build for ALTAF ARABIC.

Entry point: `index.html`

The platform is data-driven:
- `data/` contains curriculum/data manifests
- `assets/audio/core/` contains core unit MP3s
- `assets/audio/conversation/` contains Conversation Lab MP3s

This repository is intended for testing and version control. GitHub Pages is static hosting; it is not the student-results database.
